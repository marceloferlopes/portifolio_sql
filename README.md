# portifolio_sql

Portfólio E-commerce Data Analytics — PostgreSQL

**Sobre o Projeto**

Este projeto consiste na criação e análise de um **banco de dados de e-commerce**, desenvolvido em **PostgreSQL**, com dados fictícios simulando operações de vendas de uma loja virtual.

O objetivo principal é demonstrar conhecimentos práticos em **SQL, modelagem de banco de dados e análise de dados**, utilizando consultas para extrair informações relevantes sobre o desempenho das vendas.

O projeto foi desenvolvido como parte do meu **portfólio profissional na área de Dados**, com foco no desenvolvimento de habilidades aplicáveis à rotina de um Analista de Dados / BI.


**Objetivos do Projeto**

- Criar um banco de dados relacional estruturado;
- Aplicar conceitos de modelagem e relacionamento entre tabelas;
- Utilizar Primary Keys e Foreign Keys;
- Inserir e organizar dados de vendas;
- Desenvolver consultas SQL para análise dos dados;
- Identificar indicadores de desempenho do e-commerce;
- Transformar dados brutos em informações úteis para tomada de decisão.


**Estrutura do Banco de Dados**

O banco foi estruturado de forma relacional, utilizando tabelas integradas por meio de **chaves primárias (PK)** e **chaves estrangeiras (FK)**.

Entre as principais entidades do projeto estão:
**Clientes**
**Produtos**
**Categorias**
**Pedidos**
**Itens dos Pedidos**
**Vendedores**

A estrutura foi desenvolvida buscando representar, de forma simplificada, o funcionamento de um e-commerce real.


**Etapas do Projeto**

1. Modelagem do Banco de Dados

Criação da estrutura do banco de dados no PostgreSQL, definindo:

- Tabelas;
- Colunas;
- Tipos de dados;
- Chaves primárias;
- Chaves estrangeiras;
- Relacionamentos entre as tabelas.

2. Geração dos Dados

Criação de dados fictícios para simular operações reais de um e-commerce, incluindo:

- Clientes;
- Produtos;
- Categorias;
- Vendedores;
- Pedidos;
- Itens vendidos;
- Datas e valores das vendas.

3. Inserção dos Dados

Inserção dos registros nas tabelas do banco de dados, respeitando os relacionamentos definidos na modelagem.

4. Análise dos Dados

Desenvolvimento de consultas SQL para responder perguntas de negócio, como:

- Qual foi o faturamento total?
- Quais produtos foram mais vendidos?
- Qual vendedor apresentou o maior faturamento?


**Conhecimentos de SQL Aplicados**

Durante o desenvolvimento do projeto foram utilizados conceitos como:

- `SELECT`
- `WHERE`
- `ORDER BY`
- `GROUP BY`
- `JOIN`
- Funções de agregação (`SUM`)
- Funções de data
- Cálculos e métricas de negócio
- Criação e alteração de tabelas (`CREATE`, `ALTER`)
- Inserção de dados (`INSERT`)
- Relacionamentos entre tabelas
- Primary Keys e Foreign Keys


**Ferramentas Utilizadas**

PostgreSQL

Banco de dados utilizado para criação, armazenamento e consulta dos dados.

DBeaver

Ferramenta utilizada para:

* Criação das tabelas;
* Inserção dos dados;
* Desenvolvimento das consultas SQL;
* Validação dos resultados;
* Análise dos dados.

Inteligência Artificial

Utilizada como ferramenta de apoio na geração dos **dados fictícios**, contribuindo para a produtividade durante o desenvolvimento do projeto.
